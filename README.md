## 🚀 កំណែអាប់ដេតថ្មី v2.6.0 (Latest Release)

- **🎨 បង្កើតស្លាយតាម Gemini Web (Master Prompt):**
  - ជំនួសប៊ូតុង PPTX ចាស់ដោយប្រព័ន្ធ **2-Step Workflow** ដំណើរការផ្ទាល់ជាមួយ Gemini Web កម្រិតខ្ពស់
  - រូបភាពអប់រំ AI ស៊ីមេទ្រីស្អាតៗគ្រប់ស្លាយទាំងអស់ (គ្មានរូប Placeholder ប្រផេះឡើយ)
  - ក្បួនរចនាអក្សរខ្មែរ (Khmer Typography Hierarchy) ធំៗច្បាស់ៗ ងាយស្រួលមើលក្នុងថ្នាក់រៀន
  - ផ្ទាំង Preview Prompt ជាមួយមុខងារ **កូពី Prompt** និងបើក Gemini Web ដោយស្វ័យប្រវត្តិ
- **🔄 ប្រព័ន្ធ Cache Auto-Sync (v40):**
  - បង្កើនល្បឿន និងជម្រះ Cache ចាស់នៅលើ Browser ដោយស្វ័យប្រវត្តិ
- **⚡ Vercel Serverless Integration:**
  - ដំណើរការរលូន ១០០% លើ Vercel Cloud Edge Network

## 🛠️ បច្ចេកវិទ្យាប្រើប្រាស់ (Tech Stack)

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Kantumruy Pro, Battambang, FontAwesome)
- **Backend:** Python 3.14 / Flask (Vercel Serverless WSGI)
- **AI Integrations:** Google Gemini 2.5/Flash, NotebookLM, Pollinations AI, Groq
- **Hosting:** GitHub + Vercel Cloud Auto-Deployment
